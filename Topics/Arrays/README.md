# 📖 Theory

## What is an Array?

An array is a linear data structure that stores elements of the same
data type in contiguous memory locations.

Example:

[10, 20, 30, 40, 50]

Properties:

- Fixed indexing
- O(1) random access
- Contiguous memory
- Cache friendly
- Same data type

# Interview Tips

✔ Always ask if the array is sorted.

✔ Check constraints before selecting an algorithm.

✔ Try solving in O(1) extra space whenever possible.

✔ Think whether hashing can reduce time complexity.

✔ Watch for integer overflow.
